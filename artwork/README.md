# GoreeCloud Drive Artwork

This directory is the canonical repository location for GoreeCloud Drive's official icon, logo, and application artwork.

The final approved artwork has not yet been committed. Until an official asset is approved and stored here, release/package metadata must not substitute unrelated GoreeCloud artwork or generate an unofficial icon during packaging.

Required future source assets should include scalable originals plus platform exports needed by web, Android, Linux/Debian, documentation, and public websites.
