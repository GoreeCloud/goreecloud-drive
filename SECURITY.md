# Security Policy

GoreeCloud Drive is currently in **Development** and must not be represented as production-ready or Stable.

## Reporting a vulnerability

Please use GitHub's private security-advisory workflow for this repository when available. Do not disclose exploitable details in a public issue before a coordinated fix can be prepared.

## Sensitive information

Never commit passwords, API tokens, private keys, recovery codes, signing material, production environment files, private user data, or database exports. Example configuration must contain placeholders or non-sensitive development defaults only.

## Security acceptance

A successful build or CI run proves only the checks performed. Production acceptance additionally requires the applicable authorization, cross-user isolation, target-runtime, dependency, backup/restore, rollback, monitoring, privacy, accessibility, integration, and release-candidate evidence.
